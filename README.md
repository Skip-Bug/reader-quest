# reader-quest

Интерактивный тренажёр для подготовки к собеседованиям по Python: вопросы и
ответы из Markdown-файла, автотемы, прогресс и экзамен.

## Возможности

- **Изучение** — один вопрос за раз: сначала подумайте, потом откройте ответ;
  отметки «Знал» / «Повторить» и навигация назад/вперёд.
- **Экзамен** — серия случайных вопросов с самооценкой; результат переносится
  в прогресс одной кнопкой.
- **Статистика** — освоенность по темам, слабые темы сверху, кнопка «учить тему».
- **Сайдбар** — поиск по тексту, фильтр по темам и статусам, порядок, прогресс.
- **Прогресс** сохраняется в `.reader_quest/progress.json` между запусками.
- **Экспорт**: `python highlight.py` собирает автономный
  `Python_Developer_Questions.html` — тёмная тема One Dark, список вопросов,
  поиск и отметки в localStorage; файл открывается офлайн в любом браузере.

## Запуск

```bash
uv sync                     # установка зависимостей
uv run reader-quest         # запуск приложения (streamlit run app.py)
```

или классически: `uv run streamlit run app.py`.

Приложение само находит `*.md` с вопросами рядом с `app.py`
(нужно ≥ 20 заголовков вида `## 1. Вопрос`).

## Генерация статичного HTML

```bash
uv run reader-quest build   # Python_Developer_Questions.html
uv run python highlight.py --md   # то же + подсвеченный Markdown
uv run python highlight.py --help # другие варианты
```

> Приложению прогонять файлы через скрипт не нужно: оно парсит исходный
> Markdown и подсвечивает всё само. Скрипт — только для офлайн-HTML.
> Если в папке лежат дубликаты сборника (например «400 вопросов…» и
> `Python_Developer_Questions.md`), приложение покажет их как один источник.

## Структура

| Путь                     | Назначение                                                 |
| ------------------------ | ---------------------------------------------------------- |
| `app.py`                 | входная точка Streamlit: данные, сайдбар, навигация        |
| `app_pages/study.py`     | режим «Изучение»                                           |
| `app_pages/exam.py`      | режим «Экзамен»                                            |
| `app_pages/stats.py`     | страница «Статистика»                                      |
| `src/reader_quest/`      | ядро: парсер, темы, подсветка, прогресс, HTML-экспорт, CLI |
| `highlight.py`           | CLI генерации HTML/Markdown (обёртка над ядром)            |
| `.streamlit/config.toml` | тема One Dark Pro                                          |
| `tests/`                 | pytest + Streamlit AppTest                                 |
